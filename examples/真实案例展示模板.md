# 真实案例展示模板

> 发布仓库前，请用你本人真实跑过的案例填写本文件；删除本说明中不适用于公开展示的内容。不要把虚构样例标成真实测试结果。

## 案例信息

- 案例编号：Case 01
- 测试日期：YYYY-MM-DD
- 使用环境：WorkBuddy / Codex / Claude Code / 其他（请注明）
- 输入类型：图片 / 完整草稿 / 零散想法
- 是否使用历史样本：是 / 否
- 飞书读取是否参与：是 / 否

## 原始输入

粘贴你实际发给 Agent 的内容，或放一张已获授权、已脱敏的截图。

## Skill 实际输出

原样记录 Agent 第一次返回的结果，不要先人工润色再声称这是原始输出。

## 评估

- 是否保留原意：1–5 分
- 是否贴近个人风格：1–5 分
- 是否自然、像真人表达：1–5 分
- 是否有无依据的新增信息：有 / 无
- 是否过度拔高或营销：有 / 无
- 是否可以直接发布：可以 / 需修改

## 人工修改（可选）

记录你后来改了什么、为什么改。区分 Agent 原始输出和人工修改稿。

## 复盘

这次结果证明了什么？哪里仍然不好？下个版本要改哪条规则？

- [ ] 取得素材所有者必要的授权或使用本人素材

- [ ] 未公开私人飞书表格地址、访问令牌或密码
