# 朋友圈文案润色器

**把你想说的话，变成别人能记住、关键时刻想得起你的朋友圈。**

这是一个帮你经营微信私域的 AI SKILL。你只需要发一张图片、一段草稿，或者几句零散的想法，它就能结合你的个人背景和历史朋友圈，帮你整理成符合你本人表达习惯的文案。

它不只是帮你把话写得更漂亮，也是帮你持续输出有价值、有个人特色、能够积累信任的内容。

## 一、为什么要认真经营朋友圈？

很多人做朋友圈。今天发产品，明天发优惠，后天发客户好评。

问题是，你想成交，别人也有自己的生活。

2016 年，张小龙在公开演讲中谈到，微信不应骚扰用户，不应把用户不需要的内容推给用户。他也担心朋友圈里充斥过多心灵鸡汤和诱导内容，最终让用户觉得信息杂乱，逐渐失去阅读兴趣。

这背后有一个值得重视的产品理念：**用户的注意力不是免费的，不能因为你想宣传，就随意占用别人的时间。**

对于做生意来说，这尤其重要。

你的微信好友，他们今天未必需要你的服务，但不代表未来不会需要。

在真正产生需求之前，他们可能已经通过你的朋友圈，慢慢形成了对你的判断：

- 你到底懂不懂自己做的事情？
- 你有没有真实经验，还是只会讲漂亮话？
- 你看问题有没有自己的判断？
- 你做事是否靠谱，值不值得把钱和时间交给你？

这些判断，通常不是靠一条广告完成的，而是通过长期、自然的接触逐渐形成。

所以，**朋友圈的商业价值，不只是让别人看到你在卖什么，更是让别人逐渐理解你是谁、你擅长什么，以及为什么值得找你。**

等对方真正遇到问题时，你能不能进入他的选择范围，往往取决于他此前对你积累了多少认知和信任。

## 二、什么样的朋友圈，有商业价值？

高价值内容，不等于每条都要输出干货，更不等于每条都要教育别人。

真正值得经营的内容，可以发挥以下作用。

**1. 让别人知道你有真本事**

分享真实经验、工作细节、项目判断、解决问题的过程。让别人看见你做过什么、怎么思考，而不只是听你介绍自己有多专业。

**2. 让别人逐渐认可你的判断**

针对一个行业变化、一件商业现象或一个常见误区，说出你自己的看法。观点不必惊天动地，但要有依据、有思考，不能只是把网上的热门话术换个说法。

**3. 让别人更容易理解你的价值**

你不需要每天喊自己专业。持续展示你如何分析问题、做出选择、解决实际困难，别人自然有机会判断你是否值得信任。

**4. 让关系保持自然连接**

有真实感的日常、创业经历、工作中的小发现，同样可以成为朋友圈的一部分。它们不一定直接成交，但能让别人认识一个具体的人，而不是一个只会推销服务的账号。

这些内容长期积累，可能带来几种商业上的帮助：

- **降低信任成本：** 潜在客户在联系你之前，已经对你的能力和做事方式有一定了解。
- **减少沟通成本：** 你不必每次从头解释自己是谁、做过什么、能解决什么问题。
- **提高需求匹配度：** 内容帮助合适的人理解你的服务，也让不适合的人更早作出判断。
- **增加被想起的机会：** 当别人或其身边的人遇到相关问题时，更容易想到你。

这不是保证发朋友圈就能成交的公式。真正的业务能力、服务质量和客户需求仍然决定交易能否发生。

但如果你明明有经验、有能力，却从不表达，别人就很难凭空知道这些。商业世界还没有普及读心术，这确实有点遗憾。

## 三、为什么需要这个技能？

道理大家都懂，执行起来却是另一回事。

很多人并不缺少值得分享的东西，真正缺少的是稳定输出的能力。

今天看见一件有意思的事，想发朋友圈，写了两句觉得太普通，最后放弃。

明明积累了不少经验，却不知道怎么组织语言。

让 AI 帮忙写，结果又是熟悉的配方：开头上价值，中间讲道理，结尾总结升华。内容看起来挺完整，就是不像本人会说的话。

更麻烦的是，如果每次都要先解释自己的背景、目标、表达习惯，再反复修改 AI 的结果，原本为了省时间，最后反而多了一份工作。

**朋友圈文案润色器，就是为了减少这类重复劳动。**

它会结合你的个人背景、内容策略和历史文案，帮助你把原本零散的素材，整理成更像你自己表达的内容。

它追求的不是让每个人都写出同一种漂亮文案，而是尽可能保留每个人不同的经历、判断和表达方式。

## 四、它能做什么？

| 你提供的素材 | 它会怎么处理 |
| --- | --- |
| 一张图片 | 理解图片中的信息，找到值得分享的角度，直接生成一条可发布的朋友圈 |
| 一段完整草稿 | 优先轻度润色，保留原意、个人判断和自然的表达习惯 |
| 几句零散想法 | 整理重点、调整表达顺序，让内容更清楚、更容易读懂 |
| 一段真实经历 | 提炼其中值得分享的经验或观察，不擅自编造细节 |
| 一条观点或行业观察 | 判断它是否值得发，帮助表达得更具体、更有说服力 |

它还会尽量做到：

- **贴近你的表达习惯：** 支持结合个人背景与最多 20 条真实朋友圈样本进行调整。
- **不为了发布而硬凑：** 如果素材确实缺乏可表达的价值，会明确提醒，而不是强行生成一篇看似深刻的文章。
- **不乱编故事：** 不擅自添加你的经历、客户案例、业务数据或未经证实的事实。
- **少一点 AI 腔：** 避免机械套用金句、过度总结、刻意拔高和生硬的营销话术。
- **尽量减少操作：** 默认根据你输入的素材直接处理，不要求你每次重复填写一堆指令。

## 五、适合谁使用？

这个技能尤其适合靠专业能力、个人信誉或知识服务获得收入的人。

例如：

- **创业者和小生意经营者：** 想通过朋友圈积累客户信任，而不是天天发促销信息。
- **独立顾问和专业服务者：** 有专业经验，但不擅长把自己的能力表达出来。
- **知识服务和培训从业者：** 希望让潜在客户持续了解自己的观点、经验与服务价值。
- **内容创作者和个人品牌经营者：** 不想让 AI 把自己的表达习惯磨成千篇一律的模板。
- **需要维护客户关系的业务人员：** 希望通过有价值的内容保持自然连接，而不是反复群发广告。

如果你只想输入几个关键词，就批量生成几十条促销文案，这个项目的设计目标并不是这个方向。

它更适合希望长期经营个人信誉、持续积累信任的人。

## 六、怎么使用？

最简单的方式，就是把它安装到支持技能的 AI 工具中。

安装完成后，你不需要先学习复杂的提示词。直接提供素材即可。

例如：

**输入：**

今天看到一家奶茶店，店员记得老顾客的习惯。突然觉得，做产品和做生意有个共同点：不能只盯着每次交易。

**期望得到的结果：**

AI 结合你的个人表达习惯，把这段想法整理成自然的朋友圈。重点保留你对产品与生意的观察，而不是硬凑成一篇商业管理课。

具体生成结果以实际运行效果为准。建议查看仓库中的真实案例和演示视频，了解它在实际使用中能做到什么程度。

## 八、快速安装

### 腾讯 WorkBuddy

1. 下载仓库中的 `dist/wechat-moments-polisher-workbuddy.zip`。
2. 打开 WorkBuddy 的「技能」页面，选择添加或上传本地技能包。
3. 安装后，在对话中发送图片、草稿或零散想法进行测试。

本技能包按 WorkBuddy 相关技能格式准备，首次安装后仍需在你的客户端中验证。

如果要读取飞书中的历史朋友圈，还需要另外连接飞书工具，并授予指定多维表格的读取权限。安装技能本身不会自动获得这些权限。

### Codex

将整个技能文件夹放在用户级目录 `~/.agents/skills/wechat-moments-polisher/`，或项目中的 `.agents/skills/wechat-moments-polisher/`。

目录中需要保留 `SKILL.md` 和 `references/`。

### Claude Code

将整个技能文件夹放在个人级目录 `~/.claude/skills/wechat-moments-polisher/`，或项目中的 `.claude/skills/wechat-moments-polisher/`。

目录中需要保留 `SKILL.md`。

**兼容说明：** Codex 与 Claude Code 原生支持自定义 Agent Skills；WorkBuddy 使用对应的技能包格式。不同客户端对目录位置、附加元数据和工具连接的要求可能不同，请以各自官方文档和实际测试结果为准。

## 九、如何让它更像你？

默认配置可以直接使用。想获得更贴近个人风格的结果，可以进一步完善以下文件。

**第一步：填写个人背景**

复制 `references/个人背景与内容策略模板.md`，另存为 `references/我的个人背景与内容策略.md`。

写清楚你的经历、专业能力、目标客户、业务方向和内容偏好。

**第二步：添加历史朋友圈**

复制 `references/个人风格样本模板.md`，另存为 `references/我的个人风格样本.md`。

填入最多 20 条你本人真实发布过的朋友圈。

建议覆盖不同类型的内容，例如行业观察、专业思考、高价值观点和日常生活。样本应尽量反映你真实的表达习惯，而不只是你认为自己应该呈现的形象。

**第三步：配置飞书数据源（可选）**

复制 `references/数据源配置模板.md`，另存为 `references/我的数据源配置.md`，填写目标多维表格和字段信息。

使用飞书读取功能前，需要确认对应工具已经连接，且拥有所需权限。

## 十一、隐私与安全

个人朋友圈可能包含客户信息、私人关系和业务数据。不要为了让 AI 更了解你，就把不该公开的内容一股脑塞进仓库。

- 公开仓库只保存通用规则、空白模板和已经脱敏的示例。
- 不要上传私人朋友圈原文、客户简历、聊天记录、私有飞书链接、访问令牌或其他敏感信息。
- 本技能只会依据当前可访问的信息工作，不会绕过权限。
- 读取文件或飞书失败时，不应声称读取成功。
- 安装第三方技能前，应检查其中的指令、脚本和外部连接能力。
