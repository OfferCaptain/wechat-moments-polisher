# 30 秒演示视频脚本

## 演示目标

让没看过项目的人在 30 秒内看懂：你输入的是什么、Skill 实际做了什么、结果有什么价值。

## 录制前准备

1. 选一段你平时真实会发给 Agent 的草稿，或一张可以公开的日常/产品截图。
2. 在你实际使用的 Agent 中启用本 Skill，并准备好要展示的个人样本（只用可公开样本）。
3. 先完整跑一次，确认效果自然、无隐私信息，再开始录屏。
4. 关闭通知，隐藏账号邮件、客户信息、私人表格和无关窗口。

## 30 秒分镜

| 时间      | 画面            | 屏幕上的内容                               |
| ------- | ------------- | ------------------------------------ |
| 0–3 秒   | 显示原始素材        | 一张图片，或一段不太顺的原始草稿                     |
| 3–7 秒   | 在 Agent 中输入任务 | “请根据我的历史朋友圈风格，直接润色这条内容。”             |
| 7–18 秒  | 展示实际生成过程与结果   | 不加戏，展示 Agent 原始返回的一条成稿               |
| 18–24 秒 | 快速展示关键规则      | “最多 20 条个人样本 / 保留原意 / 不编造 / 不硬凹深度”   |
| 24–30 秒 | 展示项目仓库地址      | “开源的中文朋友圈 Skill，欢迎试用、提 Issue 和贡献案例。” |

## macOS 录制方式

1. 按 `Shift + Command + 5` 打开 macOS 截图工具栏。
2. 选择录制整个屏幕或选定区域，点击录制。
3. 完成操作后停止录制，先检查是否意外录入隐私内容。
4. README 优先放简短 GIF；也可以在 README 放静态截图，并把 MP4 链接放到 `docs/`。
5. 录制内容含私人素材时，不要上传到在线 GIF 转换网站。先脱敏，或使用本地工具处理。

## GIF 建议

- 控制在 20–30 秒；
- 画面裁剪到 Agent 对话窗口，避免显示整个桌面；
- 字号足够大，生成结果至少停留 5 秒；
- 去掉等待、加载和无关操作；
- 不要剪掉关键失败结果或把人工修改稿冒充 Skill 原始输出。
